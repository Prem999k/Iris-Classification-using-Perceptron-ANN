# 🌸 Iris Classification using Perceptron & ANN (Deep Learning Project)

## 📌 Project Overview

This project demonstrates the implementation of Machine Learning (Perceptron) and Deep Learning (Artificial Neural Network - ANN) models on the **Iris Dataset**.

The goal is to classify iris flowers into three species based on their physical features and compare the performance of linear and non-linear models.

---

## 🎯 Objectives

* Build a Perceptron model for classification
* Build an Artificial Neural Network (ANN) using Keras
* Compare performance between traditional ML and Deep Learning
* Understand how neural networks improve accuracy

---

## 📊 Dataset Information

* Dataset: **Iris Dataset (Scikit-learn)**
* Total Samples: 150
* Features:

  * Sepal Length
  * Sepal Width
  * Petal Length
  * Petal Width

### Target Classes:

* Setosa
* Versicolor
* Virginica

---

* **Language:** Python

---

## 🧠 Models Used

### 🔹 1. Perceptron Model

* Linear classification algorithm
* Suitable for linearly separable data
* Implemented using Scikit-learn

---

### 🔹 2. Artificial Neural Network (ANN)

* Multi-layer neural network
* Handles non-linear relationships
* Built using Keras Sequential API

📌 **ANN Architecture:**

* Input Layer: 4 neurons
* Hidden Layer(s): Dense + ReLU
* Output Layer: 3 neurons + Softmax
